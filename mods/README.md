# Изображения модов

Каждый мод получает отдельный каталог `mods/<slug>/`. Использовать стабильный
slug из рабочего репозитория, не отображаемое название Steam.

```text
mods/<slug>/
  README.md          # назначение файлов, атрибуция, ссылки
  common/            # изображения мода без привязки к языку, если нужны
  ru/cover-v1.png    # русская обложка
  en/cover-v1.png    # английская обложка, если подготовлена
```

Сюда загружать готовые обложки, баннеры, скриншоты и карточки конкретного
мода. Общий бренд и разделители остаются в `shared/`; дублировать их для
каждого мода не нужно. Каталоги создавать по мере появления готовых файлов.

В именах использовать понятное назначение и версию: `cover-v1.png`,
`features-v1.png`. Новую редакцию выпускать как v2; старые ссылки сохранять.
Не заменять PNG на JPEG при необходимости прозрачности. После push проверять
прямую raw-ссылку и совпадение загруженного файла с локальным.

Оригинальные моды и исходные обложки не присваивать: в README мода сохранять
ссылку на источник и вклад авторов. Локальные исходники, скрипты и отчёты
остаются в рабочем репозитории. Публикация картинки не обновляет сам мод в Steam.
