# Отметка русского перевода

[ru-flag-nm-v1.png](ru-flag-nm-v1.png) — PNG RGBA 640×440, флаг России с логотипом NM поверх него. Внешний фон прозрачный, пропорции флага 3:2.

Накладывать одной отметкой на ОРИГИНАЛЬНУЮ обложку мода. Выбирать правый верхний или правый нижний угол так, чтобы не закрыть название и ник автора. Сравнить оба угла и визуально проверить итог. Если нужно, уменьшить отметку, сохранив пропорции. Если безопасного места нет, согласовать компоновку. Не добавлять второй флаг и не использовать чужой русификатор как исходную картинку.

Сохранять атрибуцию оригинального арта. Готовые обложки хранить в mods/<slug>/ru/cover-vN.png. Для собственных модов флаг не добавлять автоматически.

Шаблон представляет авторство перевода, а не оригинального мода. Предыдущие отдельные флаг и печать на GrimWorld v1 остаются историческим примером.

Исходный скрипт: docs/branding/build_translation_badge.py; helper наложения и подробности: docs/branding/translation-badge/ в рабочем репозитории модов.
